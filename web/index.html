      哪些文件可以转换？

      常见本地音频

      MP3、FLAC、WAV、M4A、AAC、Ogg、Opus、APE 等，可以自动识别并转换。

      部分音乐平台格式

      已接通常见 NCM、QMC v1，以及带可恢复内嵌密钥的部分 QMC v2；支持 KWM 和 KGM／KGMA／VPR 的 type 2、type 3（slot 1）。直接上传即可自动识别。QQ 的 STag、musicex 和酷狗 type 4 等版本暂不支持，上传后会说明原因。

      音质与下载

      改后缀不能改变音频格式。有损音频转为无损格式，也不能提升原来的音质。

      转换后的文件只保留在当前页面，刷新或关闭后需要重新转换。仅上传你有权处理的文件。
